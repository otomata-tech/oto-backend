## prerequisite — connecte ton compte X (Twitter)

ton compte X est connecté par un flux hébergé ; l'outil ne touche QUE les messages privés (DM) — il ne publie pas et ne lit pas la timeline.
- la clé d'abonnement vit sur le connecteur **Compte Unipile** (ta clé BYO, ou celle de la plateforme avec l'option **messagerie hébergée** accordée par un admin) ;
- puis « Connecter mon compte X (Twitter) » ici. pas de cookie à coller ni d'extension.

## usage — lire et répondre depuis ton compte

`twitter_chat(op=list|read|send)` — tu agis comme toi-même, sous ton propre compte.
- « lis mes DM X non lus »
- « réponds à [pseudo] en DM »
- « résume ma conversation avec [pseudo] »

## note — le code du canal reste `TWITTER`

le code du canal reste `TWITTER` côté plomberie : un message d'erreur qui dit « twitter » parle bien de X.
